# 🚀 PixForge – AI Image Generator

PixForge is a full-stack web application that transforms text prompts into stunning AI-generated images. It showcases real-world SaaS architecture with authentication, API integration, and a credit-based system.

---

## 🌟 Features

- 🎨 Generate AI images from text prompts  
- 🔐 User Authentication (JWT-based Login/Signup)  
- 💳 Credit-based usage system  
- ⚡ Fast and responsive UI  
- 🖼️ Download generated images  
- 🔄 Loading states and error handling  
- 🌐 Full-stack implementation  

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Tailwind CSS
- React Router

### Backend
- Node.js
- Express.js
- MongoDB (Mongoose)

### Authentication
- JWT (JSON Web Tokens)
- bcrypt.js

### APIs
- AI Image Generation API (OpenAI / Cloudinary)
